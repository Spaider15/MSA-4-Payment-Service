# Задание 1. Шаги Saga

Реестр транзакций Saga для процесса оплаты заказа на маркетплейсе.

| Транзакция | Описание | Тип | Компенсация |
|---|---|---|---|
| CREATE_PAYMENT | Создание платежа в Payment Service в статусе CREATED | Компенсируемая | CANCEL_PAYMENT |
| DEBIT_CUSTOMER_FUNDS | Списание денег со счета клиента на транзитный счет платформы | Компенсируемая | REFUND_CUSTOMER_FUNDS |
| FRAUD_CHECK | Проверка в FraudCheck Service, внутри параллельно FRAUD_RULES_CHECK (внутренние правила), AML_CHECK и GEO_RISK_CHECK (внешние провайдеры). Результат: разрешение, запрет или ручная проверка. Есть cut-off - если ответа нет, считаем что разрешено | Компенсируемая | - (только чтение, откатывать нечего) |
| REQUEST_MANUAL_REVIEW | Создание задачи оператору на ручную проверку, ждем решение до 20 минут, потом cut-off | Компенсируемая | CANCEL_MANUAL_REVIEW |
| TRANSFER_TO_COUNTERPARTY | Перевод денег контрагенту. Pivot-точка, после нее назад откатить уже нельзя | Необратимая | - |
| COMPLETE_PAYMENT | Перевод платежа в статус COMPLETED | Повторяемая | - |
| RECORD_ACCOUNTING_ENTRY | Отправка проводки в учетную систему (отдел Финансы) | Повторяемая | - |
| NOTIFY_CUSTOMER_SUCCESS | Уведомление клиента об успешной оплате | Повторяемая | - |
| CANCEL_MANUAL_REVIEW | Отзыв задачи у оператора (например клиент отменил платеж во время проверки) | Повторяемая | - |
| REFUND_CUSTOMER_FUNDS | Возврат денег клиенту с транзитного счета | Повторяемая | - |
| CANCEL_PAYMENT | Перевод платежа в финальный статус DECLINED / CANCELLED / FAILED | Повторяемая | - |
| NOTIFY_SECURITY_FRAUD_ALERT | Уведомление службы безопасности о подозрительной операции | Повторяемая | - |
| NOTIFY_CUSTOMER_DECLINED | Уведомление клиента об отказе и возврате денег | Повторяемая | - |

Пояснения:
- Все шаги до TRANSFER_TO_COUNTERPARTY компенсируемые, после него только повторяемые.
- Компенсации (REFUND, CANCEL и т.д.) тоже повторяемые - ретраим пока не пройдут, иначе деньги зависнут. Все команды идемпотентны по paymentId, чтобы при повторе не было двойного списания/возврата.
- Если антифрод вернул запрет, возврат денег и уведомление в безопасность идут параллельно, чтобы клиенту вернули деньги сразу.
